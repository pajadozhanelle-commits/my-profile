PROFILE WEBSITE — DEPLOYMENT NOTES

Files:
- index.html: website page (GitHub Pages entry point)
- style.css: responsive styling, Outfit + Quicksand fonts
- images/: three passion-project images
- font-style-guide.png: Canva font style guide
- projects.xml: XML assignment file (kept alongside the site)

Preview locally: open index.html in a browser. Keep the folder structure unchanged.

Publish with GitHub Pages:
1. Sign in to GitHub and create a new public repository (for example, zhan-profile).
2. Upload index.html, style.css, font-style-guide.png, projects.xml, and the images folder to the repository root.
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
5. Wait for GitHub Pages to publish. The public URL will appear in Settings > Pages.
6. Open that URL in a private/incognito browser window to confirm it works without login.

Before submitting, validate index.html at https://validator.w3.org/ and style.css at https://jigsaw.w3.org/css-validator/.
